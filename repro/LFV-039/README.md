# equals(null) throws in KeywordAttributeImpl and MutableValue, and DecodedTriangle.equals throws ClassCastException

Bug LFV-039 · Area: analysis, util and document / equals methods · Priority: low · Impact: crash · Novelty: known upstream

AI-assisted finding, confirmed by automated checks, not yet triaged by a human Lucene committer. This site files nothing upstream.

## What it shows

You call equals(null) on a KeywordAttributeImpl or MutableValue, or compare a ShapeField.DecodedTriangle with an object of another type. You expect false, per the equals contract. Instead an exception is thrown (ClassCastException for DecodedTriangle).

## Expected vs actual

- Expected: You expect false, per the equals contract.
- Actual: An exception is thrown (ClassCastException for DecodedTriangle).

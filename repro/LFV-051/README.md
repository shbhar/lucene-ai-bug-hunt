# Sandbox histogram collector drops counts for values near Long.MAX_VALUE

Bug LFV-051 · Area: sandbox / facets · Priority: low · Impact: silent wrong results · Novelty: new

AI-assisted finding, confirmed by automated checks, not yet triaged by a human Lucene committer. This site files nothing upstream.

## What it shows

You compute a histogram with the sandbox HistogramCollectorManager over a point field that contains values near Long.MAX_VALUE. You expect every value to be counted in its bucket. Instead leafMax + 1 overflows and counts are dropped; a segment whose maximum is Long.MAX_VALUE loses all its counts, so results depend on the flush/merge layout.

The test shows that the sandbox HistogramCollectorManager's point-tree bulk path drops every count of a segment whose maximum is Long.MAX_VALUE (one LongField doc at Long.MAX_VALUE, width 2, match-all), because leafMax + 1 overflows.

## Expected vs actual

Expected: {4611686018427387903=&gt;1} (the doc in bucket floorDiv(Long.MAX_VALUE, 2), as the doc-values path counts it); actual (-ea and -da): {}.

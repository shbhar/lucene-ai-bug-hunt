Background: what @AwaitsFix does

#
  1. @AwaitsFix(bugUrl = ...) is an annotation of Lucene's test framework for "tests which exhibit a known issue and are temporarily disabled". It sits on a test method or on a whole test class.
  2. It is a switch. Tests that carry it belong to a test group that is off by default. They run only with -Ptests.awaitsfix=true (in Lucene's build) or -Dtests.awaitsfix=true. A skipped test is reported as skipped, and the build stays green.
  3. bugUrl is free text ("Point to JIRA entry."). Nothing reads the state of the issue it names. The annotation stays until someone deletes the line.

How the switch works

#

Line numbers are those of main 781025d6fe32; LuceneTestCase.java is the same file on branch_11x.

  1. LuceneTestCase.java:162-172: the annotation. Line 166 puts it into a test group that is off by default: @TestGroup(enabled = false, sysProperty = SYSPROP_AWAITSFIX). Lines 167-168 repeat the switch as a tag (@Tag("awaitsfix"), @TagState(...)); for the three tests here line 166 is the one that acts.
  2. LuceneTestCaseParent.java:179: the property is tests.awaitsfix. TestsAndRandomizationPlugin.java:287-290 passes the build option of the same name to the test JVM ("Enables or disables @AwaitsFix tests.", default false).
  3. bugUrl (lines 170-171) is a string. No code reads the issue it names.

The full argument555 words

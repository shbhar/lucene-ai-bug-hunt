AI-assisted bug hunt in Apache Lucene

Formal models and scripts: priorityqueue-topdocs-merge

Tools: Dafny

These are the working models and scripts this part of the hunt used. Some encode the code as it is (a counterexample is the expected result), others a fixed or correct variant; read the header comment of each file. Paths inside them were replaced by placeholders such as $LUCENE (a Lucene checkout) and $WORK.

Bugs found

  • TopDocs.merge(start, topN,...) returns a page of null ScoreDocs, with no error, when start + topN overflows int (for example start = 1 and topN = Integer.MAX_VALUE meaning 'no limit') (bug LFV-262; repro)
  • TopDocs.merge with a custom tie breaker fails an assertion (only with -ea) when the tie breaker returns 0 for tied hits from two different shards at the same rank (bug LFV-267; repro)
  • PriorityQueue.downHeap computes the child index i << 1 in int, so a queue holding 2^30 or more elements throws ArrayIndexOutOfBoundsException from updateTop, pop or insertWithOverflow and is left with one element lost and another duplicated (bug LFV-294; repro)

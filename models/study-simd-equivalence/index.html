AI-assisted bug hunt in Apache Lucene

Formal models and scripts: study-simd-equivalence

Tools: SMT-LIB (Z3/cvc5), Python

These are the working models and scripts this part of the hunt used. Some encode the code as it is (a counterexample is the expected result), others a fixed or correct variant; read the header comment of each file. Paths inside them were replaced by placeholders such as $LUCENE (a Lucene checkout) and $WORK.

Bugs found

  • Doc-values range queries with a skip index return wrong hits when a segment's values span more than Long.MAX_VALUE (bug LFV-044; repro)
  • Panama minMaxScalarQuantize rounds differently from the default implementation at one boundary value (bug LFV-071; repro)

How to run

  • SMT-LIB: z3 <file>.smt2 or cvc5 <file>.smt2 (sat with a model is a counterexample where the query asks for one).
  • Python: python3 <file>.py; scripts that import z3 need the z3-solver package.

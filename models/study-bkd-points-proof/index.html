AI-assisted bug hunt in Apache Lucene

Formal models and scripts: study-bkd-points-proof

Tools: Dafny, Python

These are the working models and scripts this part of the hunt used. Some encode the code as it is (a counterexample is the expected result), others a fixed or correct variant; read the header comment of each file. Paths inside them were replaced by placeholders such as $LUCENE (a Lucene checkout) and $WORK.

Bugs found

  • PointInSetQuery silently misses most matches on selectively indexed points (fewer index dimensions than data dimensions) (bug LFV-006; repro · bug page)
  • Sandbox HistogramCollector counts deleted documents for a PointRangeQuery (bug LFV-078; repro)
  • Flexible StandardQueryParser: an exclusive int/long point bound at MAX/MIN wraps around, so the query matches every document with the field instead of none (bug LFV-050; repro)
  • Flexible StandardQueryParser misses -0.0 documents for exclusive float/double bounds (bug LFV-059; repro)
  • Sandbox histogram collector drops counts for values near Long.MAX_VALUE (bug LFV-051; repro)

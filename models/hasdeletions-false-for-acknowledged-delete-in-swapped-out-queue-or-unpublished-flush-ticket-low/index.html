Tools: TLA+/TLC

These are the working models and scripts this part of the hunt used. Some encode the code as it is (a counterexample is the expected result), others a fixed or correct variant; read the header comment of each file. Paths inside them were replaced by placeholders such as $LUCENE (a Lucene checkout) and $WORK.

Findings

  • IndexWriter.hasDeletions() returns false for an acknowledged buffered delete while another thread's commit(), flush() or NRT reader open is writing a segment, because DocumentsWriter.anyDeletions() reads only the current delete queue and not the deletes frozen into flush tickets that are not yet published (since 4.0.0) (finding LFV-1403; repro · finding page)

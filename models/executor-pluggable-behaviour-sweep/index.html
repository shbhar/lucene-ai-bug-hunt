AI-assisted bug hunt in Apache Lucene

Formal models and scripts: executor-pluggable-behaviour-sweep

Tools: TLA+/TLC

These are the working models and scripts this part of the hunt used. Some encode the code as it is (a counterexample is the expected result), others a fixed or correct variant; read the header comment of each file. Paths inside them were replaced by placeholders such as $LUCENE (a Lucene checkout) and $WORK.

Bugs found

  • Monitor's ParallelMatcher starts blocking worker tasks in its constructor that only finish releases: a Monitor#match that fails before finish (an exception such as TooManyClauses from the presearcher, or a rejected submit) leaves its workers parked on the executor forever, and an executor that runs a worker on the calling thread (CallerRunsPolicy on a saturated pool) makes Monitor#match hang (bug LFV-637; repro)

AI-assisted bug hunt in Apache Lucene

Formal models and scripts: taxonomy-writer-concurrent-add

Tools: TLA+/TLC

These are the working models and scripts this part of the hunt used. Some encode the code as it is (a counterexample is the expected result), others a fixed or correct variant; read the header comment of each file. Paths inside them were replaced by placeholders such as $LUCENE (a Lucene checkout) and $WORK.

Bugs found

  • DirectoryTaxonomyWriter gives an existing category a second ordinal after an addCategory call fails with an IOException while the writer opens its near-real-time reader, because the cache stays marked complete or the reader stays stale (bug LFV-521; repro · bug page)
  • DirectoryTaxonomyWriter gives every later category a wrong ordinal after IndexWriter rejects one enriched ordinal document: the rejected document keeps its docID but the writer's ordinal counter does not advance (bug LFV-520; repro · bug page)
  • DirectoryTaxonomyWriter counts a new ordinal in getSize before it stores that ordinal's parent, so a concurrent getParent(getSize - 1) returns 0 (the root) instead of the real parent, or throws ArrayIndexOutOfBoundsException (bug LFV-512; repro)

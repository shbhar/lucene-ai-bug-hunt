AI-assisted bug hunt in Apache Lucene

Formal models and scripts: study-quantization-smt

Tools: SMT-LIB (Z3/cvc5), Python

These are the working models and scripts this part of the hunt used. Some encode the code as it is (a counterexample is the expected result), others a fixed or correct variant; read the header comment of each file. Paths inside them were replaced by placeholders such as $LUCENE (a Lucene checkout) and $WORK.

Bugs found

  • Two antipodal COSINE vectors make the OSQ centroid zero, so flush or merge fails and the writer closes (bug LFV-047; repro · bug page)
  • COSINE vectors whose float32 squared norm underflows pass validation and give Inf/NaN scores or poison OSQ segments (bug LFV-046; repro · bug page)
  • Quantized MIP/EUCLIDEAN scores become NaN when OSQ correction terms overflow (bug LFV-064; repro)
  • Quantized MIP score of a document equal to its segment centroid is 3.0 instead of 3.5 (bug LFV-079; repro)
  • PACKED_NIBBLE quantized vectors with an odd dimension fail once raw vectors are dropped (bug LFV-065; repro)
  • OptimizedScalarQuantizer emits out-of-range codes when the interval width is deep-subnormal (bug LFV-074; repro)

How to run

  • SMT-LIB: z3 <file>.smt2 or cvc5 <file>.smt2 (sat with a model is a counterexample where the query asks for one).
  • Python: python3 <file>.py; scripts that import z3 need the z3-solver package.
